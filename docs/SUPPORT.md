# Support

## Getting Help

### GitHub Issues

For bugs, feature requests, and questions, please open an issue at:
https://github.com/zimablue-io/najimu

When reporting bugs, please include:
- Operating system and version
- Steps to reproduce
- Expected vs actual behavior
- Any error messages

### Community Support

Najimu is maintained by zimablue-io. Response times may vary.

## Known Limitations

### AI Backend Required

Najimu requires a local AI server to function. It does not include or provide AI capabilities. You must set up one of:

- [Ollama](https://ollama.ai)
- [LM Studio](https://lmstudio.ai)
- [llama.cpp](https://github.com/ggerganov/llama.cpp)

### Platform Support

Available for **macOS, Windows, and Linux**. The macOS build is a `.dmg`, the Windows build is an NSIS installer, and the Linux build is an AppImage. All three come from the same release.

### Document Formats

Supported:
- PDF files
- Markdown (.md) files

Other formats are not supported.
